# realgood platform preview

Standalone fictional, browser-local Vite preview with portfolio overview, prototype admin/dev view and tenant issue workflow.

## Deploy to Vercel

Repository: `oeflagos-ai/realgood-platform-preview`  
Branch: `main`  
Framework: Vite or Other  
Root directory: `/`  
Install command: `npm ci`  
Build command: `npm run build`  
Output directory: `dist`  
Node version: `22.x`  
Environment variables: none

No rewrites are required. Browser localStorage is per device and does not sync across devices.
