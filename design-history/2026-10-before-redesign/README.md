# realgood: earlier public website design

This is a small, deliberately isolated archive of the public homepage before the October 2026 visual redesign. It is shared by Samuel Olagbaju for portfolio review. The current application, backend, operations repository and customer data remain private.

## What to review

- [Earlier hero component](LandingHero-before-redesign.tsx): audience-specific positioning, responsive calls to action, public compliance-check entry and a body-level demo enquiry link.
- [Earlier homepage composition](HomeRoute-before-redesign.tsx): the React/TanStack route and section composition before the redesign.

These are historical frontend excerpts, not a complete runnable application or a current offer. Imports refer to components in the private application and are not included here. Historical copy must not be taken as a current service or legal claim.

## Development story

I progressed from Lovable prototyping and frontend deployment on Vercel to directing Codex-assisted work on a separate Supabase backend, authentication, storage, access rules, Stripe integration, email delivery and protected release candidates. I use AI-assisted development and remain responsible for product decisions, testing and release scope.

The current public showcase is https://getrealgood.co.uk . Wider signed-in customer access and payment release are separate from this portfolio archive.
